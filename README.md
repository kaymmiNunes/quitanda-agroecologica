# Quitanda Agroecológica

Site expositivo desenvolvido para a **Quitanda Agroecológica de Remígio-PB**. O projeto apresenta produtos agroecológicos, informações sobre agricultura familiar, consumo consciente, receitas, localização, horário de atendimento e contato direto via WhatsApp e Instagram.

## Objetivo

Criar uma presença digital simples, responsiva e funcional para a quitanda, facilitando o acesso da comunidade a informações sobre produtos naturais, práticas agroecológicas, localização, horário de funcionamento e canais de contato.

## Funcionalidades

* Página inicial com chamada para ação.
* Seção institucional sobre a quitanda.
* Apresentação da missão do projeto.
* Catálogo de produtos disponíveis.
* Organização de produtos por categorias.
* Informações nutricionais aproximadas.
* Orientações educativas sobre uso tradicional e cuidados.
* Seção sobre agroecologia e consumo consciente.
* Área sobre cooperativa e fortalecimento da agricultura familiar.
* Seção sobre Sementes da Paixão.
* Receitas com produtos do roçado.
* Localização com endereço da quitanda.
* Informações de horário de atendimento.
* Contato direto via WhatsApp.
* Link para o Instagram.
* Layout responsivo para diferentes tamanhos de tela.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
