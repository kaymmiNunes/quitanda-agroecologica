# Site Expositivo - Quitanda Agroecológica

## Objetivo

Desenvolver um site expositivo para ampliar a visibilidade de uma quitanda agroecológica local, facilitando o acesso da comunidade a informações sobre produtos naturais, localização, horário de funcionamento, formas de contato e práticas de consumo consciente.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
